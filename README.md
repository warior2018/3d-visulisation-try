# nodejs_visual — движок VOID

3D-движок на Node.js и игры на нём. Своё окно (не браузер), рисует видеокарта через
WebGPU (на Маке — поверх Metal).

**Главное правило:** всё, что может пригодиться больше чем одной игре, — в `engine/`.
Игра (`games/<название>/`) только описывает свои правила и содержимое и пользуется движком;
в `engine/` она не лезет. Новая игра = новая папка в `games/`.

## Запуск

```bash
cd ~/Desktop/Void/nodejs_visual
npm install     # после обновления — заново
npm start       # запускает games/builder (игру «Стройка»)
```

**Windows, одним файлом:** `VOID-windows.cmd` — его можно положить куда угодно (на рабочий стол) и
запускать двойным кликом. Сам скачает Node.js (если нет 22+), свежую игру с GitHub (zip, в
`%LOCALAPPDATA%\VOID\game`; сохранения не трогает), поставит библиотеки и запустит. Каждый запуск — обновление.

**Windows:** двойной клик по `start-windows.cmd` (в папке `nodejs_visual`). Нужен Node.js LTS с nodejs.org.
При первом запуске файл сам ставит библиотеки под Windows (`npm install`, нужен интернет): `node_modules`, скопированная
с Мака, на Windows не работает — окно и видеокарта (`@kmamal/sdl`, `@kmamal/gpu`) у каждой системы свои.
Ярлык на рабочий стол: правый клик по файлу → «Отправить» → «Рабочий стол (создать ярлык)».

**Ярлык VOID.app** (`~/Desktop/Void/VOID.app`, рядом с папкой `nodejs_visual`): двойной клик — игра
запускается без терминала. Перетащи его в Dock — запуск в один клик. Ярлык сам находит `node`
(Homebrew, nvm, zsh), ошибки пишет в `~/Library/Logs/VOID.log`. Собрать заново (например, с новым
значком): `npm run make:app` (`tools/make-mac-app.js`: паспорт `Info.plist`, скрипт запуска и значок,
нарисованный кодом — PNG и `.icns` без библиотек).

Библиотеки: `@kmamal/sdl` 1.0 (окно, ввод, звук — на SDL3) и `@kmamal/gpu` 1.0 (WebGPU).
Это пока предварительные версии. Движок умеет работать и со старыми (`@kmamal/sdl` 0.11.13 +
`@kmamal/gpu` 0.2.0): если с новыми что-то не так — поставь в `package.json` старые и `npm install`.
Разница одна: только на новой версии есть «относительный режим мыши» — курсор отцеплен от мыши,
поэтому на Маке он не раздувается при быстром повороте камеры («встряхни, чтобы найти указатель»).

### Как игра пользуется движком

```js
const engine = await Engine.create({ title, settingsFile, defaults, actionLabels });
engine.sound.defineAll(SOUNDS);               // свои звуки
const models = new ModelLibrary(engine.renderer);
models.load("skeleton", file, { mirrorX: true });

class GameScene extends Scene {               // своя сцена
  update(dt) { ... }  view() { ... }  drawUI(ui) { ... }  onPress(actions) { ... }
}

engine.setScene(new MenuScene({ title: "VOID", items: [...], onSelect }));
engine.run();
```

**Сцены** лежат стопкой: пауза кладётся поверх мира (`engine.push`), закрыли — вернулись
(`engine.pop`), в главное меню — всё убрать и начать заново (`engine.setScene`).
Клавиши получает только верхняя сцена. Сцена с `realtime = true` получает кадр за кадром,
остальные перерисовываются, только когда что-то поменялось.

## Игра «Стройка»

- **Главное меню:** ИГРАТЬ (или Enter), НАСТРОЙКИ, ВЫХОД.
- **В мире** (клавиши по умолчанию, все меняются в настройках): W A S D — ходить, Shift — бег,
  **Пробел — прыжок на 1.2 блока** (хватает, чтобы запрыгнуть на один блок), мышь — обзор.
- **Столкновения:** сквозь блоки не пройти, на них можно стоять и с них падать.
  Блок нельзя поставить туда, где стоит хоть одна сущность (игрок или скелет).
- **Способности — панель из 5 ячеек внизу** (система — в движке, `engine/world/abilities.js`):
  **1 — рука** (ЛКМ — удар, 10 урона, 2.5 м, раз в 1.1 с), **2 — пистолет** (ЛКМ — выстрел, 15 урона, до 40 м),
  **3 — стройка** (как в Minecraft: ЛКМ — сломать блок, ПКМ — поставить; «призрак» показывает, куда встанет блок,
  красный — нельзя). Ячейки 4 и 5 пока пустые: в настройках для них есть привязка, но без клавиши.
- **G — панель цветов** (когда выбрана стройка): появляется над способностями, цифры 1–5
  выбирают цвет. Блок в руке — того же цвета.
- **Скелеты** (50 HP) поворачиваются к игроку, от удара вспыхивают красным, при 0 HP падают,
  а их вещи переходят в твой инвентарь. Убрал блок из-под скелета — он упадёт.
- **От 1-го лица** у каждой способности своя модель «для экрана» со своими анимациями: рука
  (взмах), пистолет (отдача и вспышка), блок в руке (толчок при установке). При смене способности
  рука поднимается снизу. Рисуется отдельным слоем
  поверх мира, поэтому не проваливается в стены. От 3-го лица её нет — виден весь скелет
  со своими анимациями «для мира». Так устроено и в больших играх.
- **Скелеты появляются сами:** раз в 5 секунд в случайной точке от (-25, -25) до (25, 25),
  не ближе 6 блоков к игроку и не больше 20 живых сразу. Если игрок ближе 10 блоков —
  Если игрок ближе 12 блоков — ищут к нему дорогу (поиск пути, A*): обходят столбы и стены,
  запрыгивают на ступеньку в 1 блок, спрыгивают вниз, друг в друга не лезут. Поставил блок
  на их пути — сразу ищут новую дорогу. Если до тебя не добраться (стоишь на высоком столбе),
  подходят вплотную и ждут, а не прыгают в стену.
- **Автообновления.** Записи обновлений — `CHANGELOG.json` в корне (новая версия сверху: номер,
  дата, заголовок, список изменений). Игра раз в 2 секунды смотрит, не поменялся ли файл: сверху
  появилась версия новее той, с которой игра запущена, — в мире приходит уведомление, а в главном
  меню справа снизу появляется кнопка **ОБНОВИТЬ ДО …**. Она перезапускает игру с новым кодом
  (мир сохраняется, когда выходишь в меню), и сразу открывается окно «ЧТО НОВОГО». Кнопка «ЧТО НОВОГО»
  и номер версии — тоже в главном меню. Новая запись: `npm run update -- minor "Заголовок" "изменение" ...`
  (или `patch`, или точный номер). Если поменялись зависимости (package.json) — нужен `npm install`,
  кнопка этого не делает. В движке: `Updater` (`engine/core/updates.js`), `Engine.create({ changelog })`,
  `ChangelogScene`, у `MenuScene` — `corner` (кнопка справа снизу) и `footer` (строка слева снизу).
- **Инвентарь (I): сумка (20 ячеек) и хотбар (5 ячеек) под ней.** Клик по предмету — взять его
  «в руку» (едет за курсором), клик по ячейке — положить: там другой предмет — поменяются местами,
  такой же — сложатся. **Q** над ячейкой — выбросить один предмет (с предметом в руке — его).
  Пустая ячейка хотбара выглядит пустой (выбрана — в руке кулак); обычный предмет в хотбаре (кость)
  показывает свой значок и количество.
- **Как в ARK:** если взаимодействию нужен предмет (кормить кабана костью), он берётся только из
  ПОСЛЕДНЕЙ ячейки хотбара (5). В движке: `Taming.feed(feeder, from)` — источник еды задаёт игра.
  Выброшенное пропадает (лежащих на земле вещей пока нет).
- **Оружие — это предметы.** Пистолет, снайперка, мачете и СТРОЙКА лежат в инвентаре; что лежит
  в хотбаре, то и в панели способностей (клавиши 1–5), пустая ячейка — кулак. Порядок меняешь
  в инвентаре. Старт: пустые руки (пистолет и молот — в магазине, B; камни — на земле). Хотбар — в сохранении.
  В движке: `InventoryScene({ sections, onChange, onDrop })` — несколько секций и перенос,
  действие `drop` (Q), предметы могут рисовать свой значок (`itemInfo → drawIcon`).
- **МАЧЕТЕ** — оружие ближнего боя: 25 урона, достаёт на 2.9 м, удар раз в 0.65 с (зажми ЛКМ —
  рубит дальше). Модель от 1-го лица — в `tools/make-viewmodels.js` (`fp-machete.glb`).
- **B — магазин** (движок: `Shop` в `engine/economy/shop.js`, окно `ShopScene`, действие `shop`).
  Позиция — слот: имя, цена, сколько в продаже (`stock`), условие появления (`when` — триггер),
  что даёт (`give`), есть ли куда выдать (`canGive`), описание и значок. Платишь монетами
  (падают с мобов). Всё без ограничений (выбросил оружие — купи снова): ПИСТОЛЕТ 45, АВТОМАТ 150, СНАЙПЕРКА 150,
  МАЧЕТЕ 70, КАТАНА 150, СТРОЙКА 8, АПТЕЧКА 15 (+40 HP). Купленное оружие — в хотбар, нет места — в сумку.
- **СНАЙПЕРКА** — покупается в магазине, ложится в хотбар: урон 90, обойма 5, бьёт на 90 м, перезарядка 2 с
  (после выстрела выходит из оптики и передёргивает затвор: анимация `Bolt` и звук «чк-клац»; держишь ПКМ —
  по готовности снова в оптике),
  с ней на 10 % медленнее. ПКМ — оптика: сильное приближение, толстый круг прицела с перекрестием,
  всё вне круга размыто (размеры — `SCOPE` в `hud.js`). Размытие — возможность рендерера движка:
  вид сцены может вернуть `blur: { radius, feather, strength, dim }` — мир тогда рисуется в отдельную
  картинку, а шейдер `blur_fs` переносит её на экран: в круге чётко, снаружи размыто. Модель — в `tools/make-viewmodels.js` (`fp-rifle.glb`).
- **Хедшоты.** У каждого существа есть хитбокс головы (`HITBOXES` в `games/builder/creatures.js`):
  попал в голову — урон ×2 (зомби в каске — ×1.5, и броня ещё режет), отметка у прицела
  красная и «ХЕДШОТ!». Работает для пистолета, снайперки и руки. Голова кабана — спереди у морды,
  поворачивается вместе с ним. В движке: `entity.hitboxes` — части тела `{ id, min, max, multiplier }`
  в осях существа; `EntityManager.raycast` возвращает и `part`; атака умножает урон на
  `part.multiplier` после всех модификаторов и ставит ярлык `headshot`.
- **Классы существ** (движок, `engine/world/creatures.js`): база — `Entity` (здоровье, инвентарь,
  статусы, сторона `faction`, с кем враждует `hostileTo`, скорость `speed`, «мозги» `brain`).
  От неё: `Player` — герой; `Mob` — враг (опыт `xp`, атака `attack`); `NPC` — мирный житель:
  неуязвим (атаки его пропускают), ни с кем не враждует, есть заготовки `role` и `dialog`
  на будущее. В игре вид задаёт `kind` в `CREATURES` (`games/builder/creatures.js`).
- **Страж растёт вместе с мобами** (тот же счёт появлений): здоровье — как у мобов (+12 за каждого,
  после 20 мобов 540), урон — медленнее (+1.5 за каждые 5). Числа — `WARDEN_GROWTH` в `config.js`.
- **ИИ — отдельная часть движка, `engine/ai/`:** `brain.js` (база «мозгов»), `hostile.js`
  (`HostileBrain` — враг: ищет ближайшего, с кем враждует, идёт по пути, бьёт, поднимает стадо),
  `wander.js` (`WanderBrain` — гуляет вокруг дома, смотрит на подошедшего героя),
  `social.js` (стадо — `alertHerd`), `pathfinder.js` (поиск пути A*, `Navigator`).
  Игра каждый кадр зовёт `e.brain.update(e, ctx, dt)`.
- **ЗОМБИ** — второй вид мобов (`Mob`): 75 HP, медленнее скелета (1.6 против 2.2), в каске —
  −25 % физического урона (выстрел 20 снимает 15), тянется на 25 % дальше (2.2 м), бьёт 6–11,
  даёт 45 опыта. Появляется вместо скелета в 30 % случаев (`MOB_MIX` в `config.js`); крепчает
  со счётом так же, как скелеты. На миникарте — зелёный череп. Модель — `tools/make-zombie.js`.
- **КАБАН** — мирный зверь (`NPC`): гуляет, урон по нему не проходит. Появляется редко
  (раз в 30 с с шансом 30 %, диких не больше 2 — `BOARS`). Смотришь на него вблизи и жмёшь
  **F** — даёшь кость; 5 костей — приручён (на спине появляется седло, на карте — золотая точка).
  F на своём кабане — сесть: WASD ведёт кабана (быстрее героя, Shift — ещё быстрее, прыгает
  на блок), стрелять и строить верхом можно. F ещё раз — слезть. Приручение хранится в сохранении.
  В движке: `Taming` (`engine/world/taming.js`), `Rideable`, `mount`, `dismount`
  (`engine/world/riding.js`), у `Spawner` появился `chance`. Модель — `tools/make-boar.js`.
- **СТРАЖ** — НПС-защитник: синий скелет у (-6, -6), 300 HP, восстанавливает 2 HP/с. Гуляет у дома;

- **Урон по НПС — флагом:** `invulnerable` (неуязвим совсем) и `protectedFrom` (от каких сторон урон

  больше не приручается («НЕ ДОВЕРЯЕТ»).
- **Стадо:** ударил скелета (хоть пулей издалека) — он злится на тебя и бежит за тобой

- **Скелеты крепчают:** каждый следующий из спавнера — на 2 HP больше (50, 52, 54...),
  каждые 5 — на 1 урон больше (6-й бьёт на 6–11, 11-й — на 7–12), и каждый следующий даёт
  на 2.5 % опыта больше (11-й — 38 вместо 30). Счёт хранится в
  сохранении и сбрасывается после гибели. Числа — `SKELETON_GROWTH` в `config.js`;
  в движке `Spawner` считает появления (`spawner.spawned`) и передаёт номер в `spawn(x, z, index)`.
  По краям экрана — красная вспышка, когда попали.
- **Гибель:** при 0 HP — экран «ВЫ ПОГИБЛИ» и выход в главное меню. Сохранение мира
  удаляется — следующая игра начинается с чистого мира (настройки остаются).
- **Миникарта** сверху: мир вокруг сверху (верхний блок каждого столбика, выше — светлее),
  скелеты — черепки, ты — стрелка. Север — вверх. В настройках ОБЩИЕ: вкл/выкл и слева/справа.
  Все числа — в `games/builder/config.js` (`SPAWN`, `SKELETON_AI`, `ATTACKS`).
- **Прицеливание — возможность движка** (`Aim`, `engine/input/aim.js`): плавный вход в прицел,
  приближение и замедление мыши. Каждое оружие задаёт своё `aim: { fov, sensitivity }`: fov — угол
  обзора в прицеле, sensitivity — как быстро перекрестие бежит по экрану относительно обычного
  (1 — так же, 0.5 — вдвое медленнее). Пистолет: ×1.7 и 0.6; снайперка: ×4.4 и 0.35 (`AIM_PISTOL`,
  `AIM_RIFLE` в `config.js`). В настройках УПРАВЛЕНИЕ — «МЫШЬ В ПРИЦЕЛЕ» (20–200 %), общий множитель.
- **Отдача — возможность движка** (`Recoil`, `engine/input/recoil.js`). У оружия `recoil`: схема бросков
  `pattern` ([вверх, вбок] в градусах для 1-го, 2-го... выстрела подряд), уровень `scale`, разброс
  `random`, какая доля вернётся сама (`recovery`) и как быстро, множитель в прицеле (`aim`), через сколько
  секунд схема начинается заново (`resetTime`). Пистолет: лёгкая, ствол гуляет влево-вправо и растёт
  (очередь из 5 — около 2.5° вверх, большая часть вернётся). Снайперка: один бросок около 5°.
  Числа — `RECOIL_PISTOL`, `RECOIL_RIFLE` в `config.js`.
- **Наклоны Q / E** — выглянуть из-за угла (движок: `Lean`, `engine/graphics/lean.js`): голова плавно
  кренится на 14° и сдвигается вбок на 0.4 м, но не в стену. У камеры теперь есть крен (`camera.roll`):
  его учитывают шейдеры (мир и небо) и модель оружия. Только пешком и от 1-го лица.
  Взаимодействие (кабан) — теперь **F**, полный экран — **F11** (клавиши меняются в настройках).
- **Объёмный звук — возможность движка** (`engine/audio/sound.js`). Звук стал стерео, и звуки
  смешиваются (раньше новый обрывал старый). `sound.setListener(позиция, yaw)` — где «уши» (игра ставит
  их в глаза героя каждый кадр); `sound.play("swing", { at: позиция })` — звук из точки мира:
  до 3 м — в полную силу, дальше тише (вдвое дальше — примерно вдвое тише), за 45 м не слышно;
  справа — громче в правом канале, слева — в левом, сзади — чуть глуше. Без `at` — звук «в голове».
  Радиус и затухание — `HEARING` в `config.js`. Из мира звучат: удары мобов и стража, попадания,
  блоки, гибель мобов, а ещё новые — шаги существ (копыта у кабана) и рык моба, когда он разозлился.
- **Цифры урона** (движок: `DamageNumbers`, `engine/ui/damage-numbers.js`): ударил или попал — над целью

  её цифры гаснут быстрее. Хедшот — крупно и красным, горение — оранжевым. Сущность сообщает о каждом
  полученном уроне (`entity.onDamage(damage, dealt)`), камера переводит точку мира в пиксель
  (`camera.toScreen`). Вкл/выкл — в настройках ОБЩИЕ → ЦИФРЫ УРОНА.
- **Наклон Q/E: удерживать или переключать** — настройки ОБЩИЕ → НАКЛОН Q/E. «Переключать»: нажал Q —
  наклонился влево, ещё раз Q — прямо (E — так же вправо).
- **Прицел (ПКМ): удерживать или переключать** — настройки ОБЩИЕ → ПРИЦЕЛ (ПКМ). Сменил оружие — из прицела
  выходишь сразу; в режиме «удерживать» зажатая ПКМ не переносится на новое оружие (отпусти и нажми снова).
  Оружие ещё и **достают**: пистолет 0.3 с, автомат 0.45 с, снайперка 0.7 с (`EQUIP_TIME`) — до этого
  не стреляет. В движке: `Ability({ equipTime })`, `AbilityBar.equipping`, `aim.reset()`.
- **Q/E — навыки оружия в руках.** У оружия дальнего боя (пистолет, снайперка) это наклоны; с кулаком,
  мачете и стройкой Q/E пока ничего не делают — у них будут свои приёмы. Подсказка — справа от
  панели способностей («Q/E: НАКЛОН»). Убрал оружие — выпрямился. В движке: `Ability({ skills })` —
  навыки на действиях `skill1`/`skill2` (в настройках УПРАВЛЕНИЕ — «НАВЫК ОРУЖИЯ 1/2»), у навыка
  `press` (нажали) и `hold` (каждый кадр, зажата ли клавиша).
- **Зажатая клавиша на Маке** больше не открывает меню букв с акцентами (полоска слева вверху):
  `SDL_MAC_PRESS_AND_HOLD=0` в `engine/core/env.js`.
- **Полный экран (F11) на Маке — настоящий:** отдельный «рабочий стол», как по зелёной кнопке окна
  (других окон за игрой нет). Зелёная кнопка и F11 — один режим. Если с ним что-то не так, старый режим
  (окно без рамки на весь стол) — `SDL_VIDEO_MAC_FULLSCREEN_SPACES=0 npm start` (`engine/core/env.js`).
- **Зажатая ЛКМ** — удар рукой и выстрел повторяются сами, как только прошла перезарядка
  (в движке: `autoRepeat` у способности, `AbilityBar.update(dt, ctx, input)`). Стройка так не делает.
- **Скорость с оружием:** пистолет в руках — на 5 % медленнее. **ПКМ (держать) — прицеливание:**
  камера приближается, пистолет встаёт к центру экрана, мышь медленнее, а ходьба — ещё на 10 %
  медленнее (вместе 15 %). В движке: `ability.moveSpeed` и `entity.speedBonuses` (прибавки складываются,
  статусы вроде льда умножают сверху); прицел — `viewModel.aim`.
  От 1-го лица пистолет выравнивается: ствол смотрит ровно вперёд, мушка — в центре экрана
  между зубцами целика (перекрестие в этот момент прячется — целишься мушкой). Это умеет движок:
  если в модели есть кости-точки `sight` (мушка) и `sight_rear` (целик), `ViewModel` сам
  поворачивает и двигает оружие так, чтобы они встали на центр. Новое оружие — просто добавь
  ему эти две точки в `tools/make-viewmodels.js`.
- **M — карта мира** (движок: `MapScene`). На карте и миникарте временно отмечен центр мира
  (0, 0) — красный крест; если он за краем миникарты, крест прижат к краю.
  Под миникартой и под картой — твои координаты: блок, где стоят ноги (X, Y — высота, Z).
  В движке у `MapScene` для этого есть `info: () => строка`.
- **Новый уровень** даёт очки талантов (здоровье не лечит) — по краям золотая вспышка.
- **Камни — оружие на Q.** Положи камни в хотбар и возьми их: ЛКМ — удар рукой, ПКМ — блок,
  **Q — бросок**: держи, чтобы бросить сильнее (полоска «СИЛА БРОСКА» у прицела, до 0.6 с), отпусти — летит
  по дуге (13–34 м/с). Урон 7–15 от силы, хедшот ×2, перезарядка броска 0.6 с. Это атака вида «предметы» —
  работают таланты вкладки ПРЕДМЕТЫ (ТЯЖЁЛЫЙ БРОСОК +2/ранг, ЛОВКИЕ РУКИ, яд, добивание, жажда, трофеи).

  и урон), `Projectiles` (`engine/world/projectiles.js`: полёт по дуге, попадание по хитбоксам и блокам).
- **Строят МОЛОТОМ** — его покупают в магазине (15 монет), на старте его нет (руки пустые).
- **Камни и стройка.** Блок стоит 1 камень (`BUILD` в `config.js`); нет камней — призрак красный и
  блок не ставится. Камни лежат на земле (маленькие серые точки на миникарте) и появляются сами

  камень вернулся. Число камней — на значке стройки и над панелью. Выброшенное (Q в инвентаре)

  В движке: `Pickups` (`engine/world/pickups.js`) — предметы на земле с физикой и прицелом.
- **Новый мир — с рельефом:** в круге 50 блоков холмы, 2 плато, гора (на высоте — камень, на вершине —
  снег); к краю всё плавно сходит на нет, в центре (где появляешься) ровно. На нём 6 домиков,
  2 сторожевые башни, 7 куч коробок (площадка под постройку выравнивается) и ~30 деревьев (`WORLDGEN`).

- **Добыча за участие:** нанёс врагу хоть 1 урона, а добил страж — добыча и опыт всё равно твои
  (движок: `entity.damagedBy(source)` — кто сколько нанёс и чем).
- **Обойма и перезарядка** у стрелкового оружия (движок: `RangedAttack({ magazine, reloadTime })`):
  обойма кончается, патроны — нет. Пустая — перезаряжается сама, **R** — вручную. Справа внизу —
  «12/12» и полоска перезарядки. Анимации перезарядки — у пистолета, автомата и снайперки.
- **АВТОМАТ** (магазин, 150): очереди, 8 урона, обойма 30, перезарядка 2.1 с, отдача ползёт вверх.
  Баланс стволов (урон в секунду с перезарядкой): пистолет ~35 (45 монет), автомат ~48 (150),
  снайперка ~43, но 90 за выстрел (150). Мачете — 30 урона, 70 монет.
- **Вид от 3-го лица:** оружие в руке героя, руки держат его (позы поверх ходьбы), видны выстрелы,
  перезарядка, удары, наклоны Q/E (наклоняется всё тело). В движке: `models.hold(entity, model, { bone })`
  — модель на кости, `animator.setOverlay(clip)` — слой-поза, `entity.roll` — крен; у способности —
  `held: { model, pose }`. Модели оружия «для мира» — `tools/make-weapons.js` (`w-*.glb`).
- **СМЕРТЕЛЬНЫЙ РАЗРЕЗ** (ближний бой, ярус 3, стоит 3 очка): раз в 5 с удар — гарантированный крит ×3,
  и на весь взмах: катана критует всем задетым. Справа от панели — «КРИТ X3 ГОТОВ» / «ЧЕРЕЗ 3С».
  Обычные криты (СОКРУШЕНИЕ 20 % ×2) тоже работают по каждой цели сплеша; два крита не перемножаются.
  В движке: `guaranteedCrit(множитель, секунд)` — готовность хранится на атакующем (`critTimers`),
  у модификатора в ctx есть `use` — общий для всех целей одного удара; `critCooldown(owner)` — сколько ждать.
- **ТЯЖЁЛАЯ РУКА** (ближний бой, 4 ранга): +3 урона и **+6 % к радиусу удара** за ранг (4/4: кулак достаёт с 2.5 до
  3.1 м, катана — с 3.2 до ~4 м). В движке: модификатор `reachBonus(доля)` — у модификаторов теперь есть
  `reachMultiplier(attack)`, радиус удара считает `attack.reachFor(owner)`.
- **Скорость ближнего боя.** Кулак — удар раз в 1.1 с, мачете — раз в 1.4 с (свои статы оружия).
  Талант БЫСТРЫЕ УДАРЫ ускоряет в процентах: −15 % перезарядки за ранг, 3/3 — −45 %
  (кулак 1.1 → 0.6 с, мачете 1.4 → 0.76 с). Если какому-то оружию ускорение не нужно — в движке
  есть `fixedCooldown: true` у атаки (перезарядку не меняет ни один модификатор).
- **Нашествие** — изредка (шанс 1/360 каждую секунду, в среднем раз в 6 минут) все мобы бегут
  на героя, где бы он ни был, спавн в 2.6 раза чаще (раз в ~1.9 с), до 40 мобов, 60 секунд.
  Вверху — красный отсчёт. `INVASION` в `config.js`. В движке: `RandomEvent`
  (`engine/world/events.js`) и `ctx.hunt` у мозгов мобов.
- **Кабан**: за убийство — 25 опыта; сам лечится (1 HP/с). Приручённый — на твоей стороне:
  мобы на него нападают, а ты его ранить не можешь. Верхом над панелью — его здоровье;
  убили под тобой — падаешь на землю. **Вкладка талантов КАБАН** (очки — общие):
  РЕЗВОСТЬ (+10 % скорости), ЗАЖИВЛЕНИЕ (+1 HP/с), ТОЛСТАЯ ШКУРА (+30 HP), БРОНЯ ИЗ ЩЕТИНЫ,
  РОСТ (каждую минуту +10 к макс. HP навсегда, `BOAR_GROWTH`).
- **I — инвентарь**, **V — вид от 1-го / 3-го лица**, **F5 — сохранить**, **F — полный экран**,
  **Esc — пауза.**

## Настройки

Сохраняются в `games/builder/saves/settings.json`.
Вкладки ВИДЕО, АУДИО, УПРАВЛЕНИЕ — движка, ОБЩИЕ (вид камеры) — игры.
Зелёная кнопка окна на Маке просто разворачивает окно; полный экран — F или настройки.

## Окна и тема интерфейса

Все экраны — главное меню, пауза, гибель, настройки, инвентарь, таланты — это **окна** движка
(`drawWindow` в `engine/ui/window.js`): панель с тенью, рамкой, полосой заголовка и кнопкой «X».
Свой экран игры — тоже окно: `const box = drawWindow(ui, { title, width, height })`, а внутри
рисуешь в области `box`. Окно само встаёт по центру и ужимается под маленький экран.

Как выглядят окна и кнопки, задаёт **тема** (`engine/ui/theme.js`): цвета текста, окна,
заголовка, кнопок (обычной, под мышью, выбранной), затемнения и фона. Игра меняет только
нужное: `Engine.create({ ..., theme: { accent: [...], window: { border: [...] } } })`.
У «Стройки» своя, «костяная» тема — `THEME` в `games/builder/config.js`.

Как интерфейс попадает на экран: нажатия и движения мыши только помечают «перерисовать»,
а рисуется интерфейс один раз в начале ближайшего кадра. В меню кадры рисуются, только
когда что-то поменялось, — и после этого ещё пару кадров подряд, чтобы свежая картинка
попала во все буферы окна.

## Бой (engine/combat)

Как проходит любой удар — рукой, пулей, магией, предметом или ловушкой:

```
атака.use() → кого задели → пакет урона (сколько, стихия, кто, чем)
  → модификаторы атаки и атакующего (порядок — priority: стихия, +N, ×K, крит...)
  → статус стихии (огонь поджигает, лёд замедляет, яд травит — с шансом)
  → цель: сопротивления (stats.resist) → урон → статусы
```

- **Виды атак:** `MeleeAttack` (дальность, замах — можно увернуться), `RangedAttack`
  (мгновенный луч; снаряды — позже), `MagicAttack` (мана, удар по области),
  `ItemAttack` (тратит предмет из инвентаря), `TrapAttack` (стоит в мире, срабатывает сама,
  одноразовая или с перезарядкой).
- **Модификаторы** вешаются на атаку (`modifiers: [...]`) или на сущность (`entity.modifiers` —
  бафф). Свой — `new Modifier({ priority, apply(damage, ctx) { ... } })`.
- **Сопротивления:** `stats.resist = { fire: 0.5 }` — огонь вдвое слабее; 1 — иммунитет;
  меньше 0 — уязвимость. Урон от статусов (горение, яд) тоже их учитывает.
- Атака не знает мир игры: что под прицелом и кто вокруг, игра передаёт в `ctx`.
- В «Стройке»: рука — `MeleeAttack`, пистолет — `RangedAttack`, скелет — `MeleeAttack`
  с замахом. Параметры — `games/builder/config.js` → `ATTACKS`. Например, огненный пистолет
  с критами: `pistol: { ..., element: "fire", modifiers: [critical(0.1, 2)] }`.

## Опыт и таланты

- **Опыт** — за побеждённых существ (скелет — 30). До 2-го уровня — 100, дальше каждый раз
  на 50 больше. Новый уровень: +1 очко талантов и полное здоровье.
- **Портрет героя** слева внизу (движок: `drawPortrait`): лицо в круге, вокруг — кольцо опыта,
  в кружке — уровень. Лицо рисуется символами прямо в коде (`PORTRAIT` в config.js).
- **T — дерево талантов**, 5 вкладок — по видам атак: БЛИЖНИЙ, ДАЛЬНИЙ, МАГИЯ, ПРЕДМЕТЫ,
  ЛОВУШКИ. Таланты вкладки действуют только на атаки своего вида. Ярус 2 открывается после
  2 очков во вкладке, ярус 3 — после 4. Наведи мышь — снизу описание, клик — вложить очко.
- **6-я вкладка — ВЫЖИВАНИЕ** (действует всегда): КРЕПКИЕ КОСТИ +10/20/30 к макс. HP,
  РЕГЕНЕРАЦИЯ 0.5/1/1.5/2 % макс. HP в секунду (рядом с полоской здоровья —
  зелёное «+1.5/С»), ТОЛСТАЯ КОЖА −10/20 % физического урона, ЛЁГКИЙ ШАГ +5/10/15/20 % скорости,
  НЕСОКРУШИМЫЙ +25 HP. Ярус 4 (после 6 очков во вкладке) — ТРОФЕИ, стоит 3 очка: за каждого
  убитого моба навсегда +1 % его макс. HP к твоему максимуму. **Трофеи урона** — ярус 4 в каждой вкладке
  вида атак (БЛИЖНИЙ — ТРОФЕИ БОЙЦА, ДАЛЬНИЙ — ТРОФЕИ СТРЕЛКА, у магии, предметов и ловушек — свои),
  3 очка: +0.3 % к урону ЭТОГО вида за каждое убийство, но только если добил этим видом
  (кулаком/мачете — копится ближний, пистолетом/снайперкой — дальний; добило горение от пули — тоже дальний).
  100 убийств — +30 %. Набранное — в сохранении (старые «+1 % за убийство» пересчитаны: те же убийства × 0.3).
  В движке: урон помнит вид атаки (`damage.kind`, у горения — вид атаки, которая подожгла),
  сущность — кто и чем добил (`lastHitBy`, `lastHitKind`).
  Набранное видно на экране: кружки с числами над опытом и HP (красный — +HP, у трофеев урона — свой цвет на вид атак).
  В движке: `widgets.drawBadges(ui, [{ value, color, label }], { x, y, r })`. В движке у таланта есть `cost` (цена ранга)
  и `maxRank: Infinity` (бесконечный талант).
  В движке: у таланта может быть `stats: (rank) => ({ maxHp, regen, ... })`, `talents.stats()`
  складывает их, а игра сама решает, что с ними сделать (`applyTalents` в `game-scene.js`).
  У `Entity` для этого есть `regen` (HP в секунду) и `setMaxHp()`.
- Таланты дают **модификаторы** из `engine/combat`: +урон, ×урон, перезарядка короче,
  вампиризм, добивание (×урон по раненым), первый удар (×урон по целым), крит, против
  скелетов, огненные пули (поджигают при КАЖДОМ попадании — `ELEMENTS.fire.statusChance = 1` в `config.js`; 2 ранга: поджог 7.5 % макс. HP в секунду 4 с / 15 % 5 с — горение
  считается от здоровья цели, `BURN_LEVELS` в `engine/combat/status.js`), шанс замедлить или отравить.
- Пока в игре есть только ближний бой и пистолет: таланты магии, предметов и ловушек можно
  учить уже сейчас — заработают, когда появятся такие атаки.

## Сохранение

`games/builder/saves/world.json`: блоки, игрок (позиция ног, взгляд, hp, инвентарь) и существа.
Сохраняется: СОХРАНИТЬ, F5, выход в меню, закрытие окна. Старые форматы (1 и 2) читаются.
Уровень, опыт и таланты тоже в `world.json` (формат 4); после гибели пропадают вместе с миром.
Сохранения из старой папки `nodejs_visual/saves/` при первом запуске копируются сюда сами.
Испорченный файл не теряется: переименовывается в `world.broken-….json`.
Чтобы вернуть всех скелетов, удали `world.json` (пропадут и блоки).

## Если пропал прогресс

В журнале (`games/builder/saves/log.txt`, прошлый запуск — `log-prev.txt`) при загрузке и при каждом сохранении
пишется уровень и все таланты, при гибели — тоже. Сохранение погибшего мира не стирается, а переносится в
`saves/dead/` (последние 3): чтобы вернуть мир, положи файл обратно как `saves/world.json`.

## Если игра зависла

Движок ведёт журнал `games/builder/saves/log.txt`: сцены, нажатия, настройки, ошибки
(предыдущий запуск — `log-prev.txt`). Отдельный поток-сторож следит, что игра жива: если она
не отвечает 8 секунд, он дописывает в журнал, на каком этапе кадра она застряла, и закрывает её.
Закрыть зависшую игру вручную: `Ctrl+C` в Терминале, где запущен `npm start`,
или Cmd+Option+Esc → «Завершить принудительно».

## Модели

`skeleton.glb` — glTF 2.0, собран кодом из брусков. Открывается в Blender или онлайн-просмотрщике.
Как модель оживает: `gltf.js` читает вершины, кости и ключевые кадры → `animator.js` каждый кадр
считает матрицы костей → видеокарта (`skin_vs`) двигает вершины смесью матриц их костей (**скиннинг**).
